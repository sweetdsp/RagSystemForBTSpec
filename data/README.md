# Documents

| File | What it is |
|------|------------|
| `sample_bluetooth_primer.pdf` | A ~6-page **self-written** educational primer (generated by `scripts/make_sample_pdf.py`). Used automatically when the real spec is absent so the app works out of the box. It is *not* the official specification. |
| `bluetooth_core_spec.pdf` | **You provide this.** The official Bluetooth Core Specification (copyright Bluetooth SIG, so it is not committed). |

## Getting the official specification

1. Go to <https://www.bluetooth.com/specifications/specs/> and open **Core Specification** (e.g. 5.4 or 6.x).
2. Download the PDF and save it as `data/bluetooth_core_spec.pdf`
   (or point `DEFAULT_PDF_PATH` in `.env` at it, or just upload it in the app's sidebar).

The full spec is ~3,000+ pages. Use the sidebar's **page range** to index only the volumes you need, e.g.
Vol 6 Part A (LE Physical Layer, power classes) or Vol 2 Part B (BR/EDR Baseband, AFH). Look up page numbers in
the PDF's table of contents.
